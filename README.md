# 🍊 Munchy — AI-Powered Food Scanner

Munchy is a playful, mobile-first nutrition tracking app that uses AI Photo Scan to break down calories, macros, and ingredients from a single meal photo.

## Features
- **AI Photo Scan** — Snap a meal photo and get instant nutritional analysis
- **Meal Journal** — Every scan saved automatically to your personal dashboard
- **Macro Breakdowns** — Protein, carbs, fat, and fiber at a glance
- **Secure Accounts** — Private meal history synced across sessions

## Tech Stack
- React 19 + React Router
- Tailwind CSS with custom Munchy theme (Energetic Orange + Lime Green)
- shadcn/ui components
- Python FastAPI backend

## Getting Started

```bash
# Frontend
cd frontend
yarn install
yarn start

# Backend
cd backend
pip install -r requirements.txt
python server.py
```
